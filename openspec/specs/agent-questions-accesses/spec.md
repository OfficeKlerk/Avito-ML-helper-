# agent-questions-accesses: вопросы по базе знаний и доступы

Задача A7 из [плана ML-ядра](../../../docs/team/01_ML_CORE_BACKLOG.md). Работает и по правилам, и с моделью ([agent-llm](../agent-llm/spec.md)); инструменты — из контрактов C и E.

## Requirements

### Requirement: Вопросы по базе знаний

#### Scenario: Ответ найден
- WHEN вопрос не про шаги адаптации, отсутствие или доступы, и поиск вернул фрагменты
- THEN агент отвечает текстом найденных фрагментов (не больше двух) и возвращает их в `sources`

#### Scenario: Ответа нет
- WHEN поиск ничего не вернул
- THEN агент честно говорит, что ответа в базе знаний нет, просит уточнить вопрос и называет контакт из справочника (`escalation`)

#### Scenario: Документы другой команды
- WHEN документ доступен только другой команде
- THEN его нет в ответе: права проверяет knowledge-service по токену пользователя, агент передаёт ответ поиска без изменений

### Requirement: Недостающие доступы

Системы: Confluence, Jira, GitLab, VPN, пространство команды (`confluence`, `jira`, `gitlab`, `vpn`, `team_space`).

#### Scenario: Какие доступы есть
- WHEN стажёр спрашивает про свои доступы
- THEN агент вызывает `access_list_my` и перечисляет: какие есть, какие запрошены и ждут, каких не хватает; источник — инструкция о доступах из базы знаний

#### Scenario: Запрос доступа к названной системе
- WHEN стажёр просит доступ к системе («запроси доступ к GitLab»)
- THEN агент создаёт черновик через `access_create_draft` с ключом `<request_id>:access_create_draft:<system>` и возвращает карточку `access_request`; заявка уходит на согласование только после подтверждения

#### Scenario: Доступ уже есть или уже запрошен
- WHEN доступ в статусе `granted` или `pending`
- THEN черновик не создаётся, агент говорит, что доступ уже есть или заявка ждёт согласования

#### Scenario: Не названа система — уточнение
- WHEN стажёр просит доступ, но не говорит к чему
- THEN агент перечисляет недостающие доступы, спрашивает, какой запросить, и возвращает `state` = `{"intent": "access_request"}`, `missing_fields` = `["system"]`

#### Scenario: Продолжение
- WHEN в `state` идёт запрос доступа и стажёр называет систему
- THEN агент создаёт черновик без повторного «запроси доступ»

#### Scenario: Система не положена команде
- WHEN `access_create_draft` вернул `forbidden`
- THEN агент передаёт текст отказа, карточки нет
