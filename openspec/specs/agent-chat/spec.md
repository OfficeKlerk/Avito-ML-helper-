# agent-chat: входной API, контекст пользователя и обработка без LLM

Задачи A1–A3 из [плана ML-ядра](../../../docs/team/01_ML_CORE_BACKLOG.md). Контракт — B, [`contracts/b_agent.yaml`](../../../contracts/b_agent.yaml).

## Purpose

Агент принимает от core-api сообщение стажёра с проверенным контекстом и без LLM отвечает на два вопроса: «что мне делать дальше» и «как оформить отгул или отпуск». Создание черновика заявки (A4) и ответы по базе знаний (A7) сюда не входят.

## Requirements

### Requirement: Входной API проверяет запрос по контракту B (A1)

`POST /v1/chat` принимает только запросы, которые проходят схему `ChatRequest`, и отвечает объектом по схеме `ChatResponse`.

#### Scenario: Корректный запрос
- WHEN core-api присылает запрос по схеме `ChatRequest` с заголовком `Authorization: Bearer <токен>`
- THEN агент отвечает 200 и телом по схеме `ChatResponse`

#### Scenario: Нет токена пользователя
- WHEN в запросе нет заголовка `Authorization: Bearer <токен>`
- THEN агент отвечает 401 с кодом `unauthorized` и не обрабатывает сообщение

#### Scenario: Запрос не по контракту
- WHEN тело не JSON, не проходит схему `ChatRequest` (например, пустое сообщение) или содержит неизвестный часовой пояс
- THEN агент отвечает 422 с кодом `validation`

### Requirement: Контекст пользователя собирается из запроса, без токенов (A2)

Агент собирает контекст: имя, роль, команда, неделя стажировки, наставник, руководитель, текущая дата и время в часовом поясе пользователя, прогресс, незавершённые и просроченные задачи, следующие шаги.

#### Scenario: Дата считается в часовом поясе пользователя
- WHEN `now` = `2026-11-11T22:30:00Z`, `timezone` = `Europe/Moscow`
- THEN «сегодня» для агента — 12 ноября 2026

#### Scenario: Просроченные задачи
- WHEN у незавершённой задачи срок раньше сегодняшней даты
- THEN задача попадает в список просроченных; выполненная задача — никогда

#### Scenario: Токен не попадает в промпт
- WHEN агент собирает текст контекста для модели
- THEN в тексте нет токена авторизации: контекст строится только из тела запроса, заголовки в него не передаются

### Requirement: «Что делать дальше» отвечается по правилам (A3)

#### Scenario: Есть следующие шаги
- WHEN стажёр спрашивает «Что мне делать дальше?» (или «что дальше», «с чего начать», «следующий шаг»)
- THEN агент перечисляет следующие шаги из `onboarding.next_steps` с причинами, в том же порядке

#### Scenario: Следующих шагов нет
- WHEN `onboarding.next_steps` пуст
- THEN агент говорит, что ближайшие задачи выполнены

### Requirement: Отгул и отпуск: распознать и уточнить даты (A3)

Агент распознаёт просьбу об отгуле или отпуске и извлекает даты: «сегодня», «завтра», «послезавтра», день недели («в пятницу» — ближайшая, включая сегодня), «13 ноября», «13.11», «13.11.2026», «2026-11-13», диапазоны «с 13 по 15 ноября», «13–15 ноября», «с 13.11 по 15.11». Дата без года, которая в этом году уже прошла, относится к следующему году.

#### Scenario: Даты нет — агент уточняет
- WHEN стажёр пишет «Как оформить отгул?»
- THEN агент спрашивает дату, возвращает `missing_fields` = `["date_from", "date_to"]` и `state` = `{"intent": "absence_request", "kind": "day_off"}`

#### Scenario: Продолжение диалога
- WHEN в предыдущем ответе агент уточнял дату (`state.intent` = `absence_request`), а стажёр отвечает «в пятницу»
- THEN агент продолжает оформление с этой датой, не требуя повторить слово «отгул»

#### Scenario: Смена темы
- WHEN `state.intent` = `absence_request`, а новое сообщение без дат и без слов про отгул
- THEN агент обрабатывает сообщение как новый вопрос и сбрасывает состояние

#### Scenario: Дата в прошлом
- WHEN единственная названная дата раньше сегодняшней
- THEN агент сообщает, что дата прошла, и снова спрашивает дату

#### Scenario: Даты есть, но создать черновик нечем
- WHEN даты известны, а инструмент создания черновика ещё не подключён (A4)
- THEN агент отвечает `status: degraded`, прямо пишет, что черновик не создан, не возвращает `proposed_actions` и сохраняет даты в `state`

### Requirement: Непонятый вопрос

#### Scenario: Вопрос вне правил
- WHEN сообщение не про следующие шаги и не про отсутствие
- THEN агент коротко говорит, с чем умеет помочь, и предлагает подсказки
