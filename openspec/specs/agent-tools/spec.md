# agent-tools: вызов инструментов и структурированный ответ

Задачи A4–A5 из [плана ML-ядра](../../../docs/team/01_ML_CORE_BACKLOG.md). Контракты: B (ответ агента), C (MCP-инструменты corp-mock), E (поиск knowledge-service).

## Purpose

Агент получает инструкции из базы знаний, контакты из справочника и создаёт черновики заявок через заменяемые клиенты. Ответ содержит текст, проверяемые источники, карточку черновика и подсказки следующих шагов. Ошибка инструмента никогда не превращается в сообщение об успешном действии.

## Requirements

### Requirement: Единый механизм вызова инструментов (A4)

Поиск идёт в knowledge-service (`POST /v1/search`), справочник и черновики — в corp-mock по MCP. Адреса задаются переменными `KNOWLEDGE_URL` и `MCP_URL`, поэтому один и тот же клиент работает и с заглушкой, и с настоящим сервисом.

#### Scenario: Токен и идентификатор запроса передаются дальше
- WHEN агент вызывает любой инструмент
- THEN в запросе есть заголовки `Authorization: Bearer <токен пользователя>` и `X-Request-Id: <request_id>`

#### Scenario: Каждый вызов попадает в trace
- WHEN агент вызвал инструмент
- THEN в `trace` ответа есть шаг с именем инструмента, признаком успеха, длительностью и кодом ошибки

#### Scenario: Ошибка инструмента
- WHEN инструмент вернул ошибку контракта (`forbidden`, `validation` и т. п.)
- THEN агент получает её код и текст для пользователя

#### Scenario: Инструмент недоступен
- WHEN сервис не отвечает, отвечает 5xx или дольше `TOOL_TIMEOUT_SECONDS`
- THEN вызов завершается ошибкой `unavailable`, а ответ агента получает `status: degraded`

#### Scenario: Повтор не создаёт второй черновик
- WHEN агент создаёт черновик
- THEN `idempotency_key` = `<request_id>:absence_create_draft`, поэтому повтор того же запроса возвращает тот же черновик

### Requirement: Структурированный ответ (A5)

#### Scenario: Инструкция с источником
- WHEN стажёр спрашивает про отгул или отпуск
- THEN агент ищет инструкцию в базе знаний и возвращает найденные фрагменты в `sources` без изменений; источник, которого не вернул поиск, в ответ не попадает

#### Scenario: Черновик создан
- WHEN даты известны и `absence_create_draft` вернул черновик
- THEN в ответе одна карточка в `proposed_actions`: тип `absence_request`, `external_id` = id черновика, поля «Тип», «Даты», «Согласует»; текст говорит, что заявка уйдёт на согласование только после подтверждения; `state` = null

#### Scenario: corp-mock отклонил даты
- WHEN `absence_create_draft` вернул `validation`
- THEN агент показывает текст ошибки, снова спрашивает дату и не возвращает `proposed_actions`

#### Scenario: Нет прав
- WHEN `absence_create_draft` вернул `forbidden`
- THEN агент показывает текст ошибки, завершает оформление и не возвращает `proposed_actions`

#### Scenario: Сервис заявок недоступен
- WHEN `absence_create_draft` недоступен
- THEN агент пишет, что черновик не создан, отвечает `status: degraded`, не возвращает `proposed_actions` и сохраняет даты в `state`

#### Scenario: Поиск недоступен
- WHEN поиск не ответил
- THEN агент продолжает без источников и отвечает `status: degraded`

#### Scenario: Вопрос вне правил
- WHEN агент не понял вопрос
- THEN он берёт из справочника контакт по теме `onboarding` и возвращает его в `escalation`
