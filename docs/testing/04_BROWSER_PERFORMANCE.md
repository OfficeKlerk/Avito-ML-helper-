# Q3. Отклик и доступность интерфейса

Из корня репозитория после [установки браузерных зависимостей](01_BROWSER_JOURNEY.md#запуск):

```bash
node integration/browser/run-requests.mjs performance
node integration/browser/run-requests.mjs performance-model
```

Каждый запуск создаёт отдельный локальный стенд с PostgreSQL и синтетическими данными. Второй запуск читает настройки модели из локального `.env` и использует баланс провайдера. Параметры портов и браузера те же, что для I3–I4. Отчёты `reports/q3-rules-result.json` и `reports/q3-model-result.json` содержат конфигурацию браузера и исходные замеры.

## Метод

- На ширинах 360 и 1280 px, при высоте 800 px, проверяются переход к основному содержимому, видимый фокус, открытие диалога с клавиатуры, перемещение внутри него и возврат фокуса после Escape. Проверяются предел ввода и перенос длинного сообщения.
- Открытие и закрытие диалога и появление ошибки длины замеряются по пять раз на каждой ширине. Интервал начинается на событии в браузере и заканчивается на кадре, когда изменившееся состояние доступно в DOM. Ориентир для каждого замера — менее секунды.
- Для трёх вопросов на каждой ширине фиксируется длительность POST чата от отправки запроса браузером до завершения получения ответа. Замер включает прокси, API, агента, поиск и вызовы модели, если она включена.
- Отдельный тест задерживает ответ чата до проверки интерфейса, возвращает 503 и проверяет сохранение текста и повтор. Второй задержанный запрос используется для проверки перехода в профиль во время ожидания.

## Результаты 13 ноября 2026 года

Локальный стенд на Windows 11, Intel Core i7-12700H (20 логических процессоров), 16 ГБ ОЗУ. Chrome 157.0.8103.40 без открытого окна, без искусственного ограничения сети и CPU. Модель — `openai/gpt-5.4-mini` через OpenRouter.

| Ширина | Режим | Локальные действия, мин.–макс. | POST чата, три запроса |
|---:|---|---:|---|
| 360 px | По правилам | 2–32 мс | 206, 48, 43 мс |
| 1280 px | По правилам | 2–14 мс | 42, 34, 37 мс |
| 360 px | GPT‑5.4 mini | 2–29 мс | 3973, 3182, 4777 мс |
| 1280 px | GPT‑5.4 mini | 2–15 мс | 1710, 3521, 3745 мс |

Все 60 локальных замеров уложились в секунду. На обеих ширинах длинное сообщение переносилось без горизонтальной прокрутки. При управляемой задержке интерфейс показывал ожидание и позволял перейти в профиль. После 503 текст сохранился, повтор вернул сообщение в историю.

Все запросы финального замера завершились со статусом `ok`. В первом прогоне с моделью один запрос вернулся как `degraded`. Тест теперь сохраняет длительность и статус каждого ответа и проверяет метку «Упрощённый ответ», если резервный режим сработает. Эти результаты описывают конкретный стенд и короткую выборку.
