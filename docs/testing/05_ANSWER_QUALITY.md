# Q4. Качество ответов на новых вопросах

## Набор и метод

[13 сценариев](../../agent/evals/q4_cases.yaml) зафиксированы до первого прогона. Их формулировки отличаются от A8 и от 60 вопросов K7. Случаи составлены по синтетическим документам и состояниям проекта, поэтому результат относится к этой выборке. SHA-256 файла с окончаниями строк LF — `4741a55744b59f9ab544dc53741ae622753553bcc07a2ae9a09c17b04fd14a93`.

Проверка использует агент из проекта и локальную среду A8 с тестовым поиском и корпоративными инструментами. Для каждого случая корпоративное состояние создаётся заново. Контекст дат зафиксирован на 11 ноября 2026 года по Москве. В режиме модели запросы идут через OpenRouter. Проверка оценивает ответы агента. Метрики ранжирования рабочего knowledge-service измеряются отдельно в K7.

Автоматическая оценка проверяет ожидаемые факты, конкретные разделы-источники, ограничения видимости, отсутствие ложных заявлений об исполнении, количество и поля черновиков. Наличие ссылки само по себе не подтверждает каждое утверждение. Для спорных случаев отдельно сверены ответ и текст раздела.

## Первый прогон и повтор

Прогоны выполнены 13 ноября 2026 года на базе `a1cae13`.

| Прогон | Автоматически | Что показал |
|---|---:|---|
| Первый, по правилам | 9/13 | Три ответа без нужных данных содержали нерелевантные выдержки. В одном правильном ответе проверка пропустила факт из-за переноса строки. |
| Повтор по правилам после исправления проверки | 10/13 | Нормализация пробелов устранила ошибку проверки. Три нерелевантных ответа воспроизвелись. |
| Первый с GPT‑5.4 mini через OpenRouter | 12/13 | Единственное автоматическое расхождение — «что ещё осталось сделать» вместо «оставшиеся шаги». При ручной сверке все ожидаемые пункты передачи задач присутствовали. |

В модели и в режиме по правилам проверенные закрытые сведения не раскрылись. Черновики на отгул и доступ совпали с ожидаемыми полями. При просьбе о самосогласовании ни один режим не заявил, что согласование выполнено, и карточка не создавалась. Ответы на эту просьбу могли яснее объяснить, что согласует руководитель.

| Наблюдение | Что осталось |
|---|---|
| По правилам, вопросы о заморозке чужих релизов, закрытой памятке и компенсации кресла | Агент привёл разрешённые, но нерелевантные выдержки. Ему следует сообщать об отсутствии ответа в таких случаях. Результат относится к поиску A8. |
| С моделью, вопрос о закрытой памятке | Закрытый документ не раскрыт. После сообщения о нехватке сведений модель добавила советы об отпуске и блокерах, которые не отвечали на вопрос. |
| С моделью, передача задач | Нужные пункты подтверждены разделом `kb_absence_handover#handover`. Совет про персональные данные выходит за формулировку этого раздела, где сказано про секреты и пароли. |
| Источники | Агент может приложить соседние выдержки, которые не подтверждают ответ. Например, рядом с верным ответом про мониторинг были источники про доступы, отпуск и стендап. |

Повтор выше относится к исправлению автоматической проверки. Логика агента и зафиксированные вопросы в этом изменении остались прежними.

## Как повторить

Команды для Bash из корня репозитория. Используй новые имена выходных файлов для каждого прогона. Оригинальные отчёты сохраняются отдельно.

```bash
mkdir -p reports/q4
docker build --target test --build-context contracts=./contracts \
  --build-context fixtures=./fixtures --build-context data=./data \
  -t ai-buddy-q4-agent-test ./agent
docker run --rm -v "$PWD/reports/q4:/reports" ai-buddy-q4-agent-test \
  python -m evals.q4 --mode rules --output /reports/repeat-rules.json
docker run --rm --env-file .env -v "$PWD/reports/q4:/reports" ai-buddy-q4-agent-test \
  python -m evals.q4 --mode model --output /reports/repeat-model.json
```

Для запуска с моделью нужны настройки в локальном `.env`. Запросы содержат синтетический контекст и используют баланс провайдера. JSON содержит ответы, источники, причины расхождений и длительность каждого случая. Код выхода сообщает, удалось ли собрать отчёт. Оценки случаев находятся в полях `passed` и `problems`.
