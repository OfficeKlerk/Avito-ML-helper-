## Прогон участником

Заполни эту таблицу после ручной проверки из чистой копии по [инструкции для жюри](../../README.md#быстрый-старт). Укажи проверенный коммит, дату, окружение и участника, который не писал проверяемый модуль. Если сценарий не проходит, добавь шаг, ожидаемый и фактический результат в реестр.

| Сценарий | Условие прохождения | Ручной результат |
|---|---|---|
| Вход и адаптация | У Анны отображаются команда, этап и следующий шаг с причиной. | Ожидается |
| Вопрос и источник | Ответ о стендапе содержит рабочую ссылку на раздел. Перезагрузка сохраняет вопрос и ответ. | Ожидается |
| Отгул | Помощник уточняет дату, показывает черновик и после подтверждения показывает номер заявки. Повтор и перезапуск сохраняют тот же номер. | Ожидается |
| Доступ | Стажёр запрашивает доступ из задачи. После выдачи руководителем карточка показывает выдачу, задача завершена. | Ожидается |
| Другая команда | Максим видит свои данные. Прямая ссылка на командный документ Анны даёт отказ. | Ожидается |

Отдельно приложи результат D6 с проверкой запуска, сохранности данных и возврата на предыдущую рабочую версию. После ручной проверки и D6 зафиксируй решение о приёмке на проверенном коммите.
