## Локальная проверка восстановления D6 · 15 ноября 2026 года

Windows 11, Docker 29.5.2, отдельный проект Compose и тестовая база. Из чистой копии `03db17e` стенд запустился по README командой `docker compose up -d --build --wait` без `.env`. Под учётной записью Анны отправлена тестовая заявка на отгул. При переключении версий `docker compose down` сохранял том PostgreSQL.

Первый запуск предыдущей версии `76f8a46` на Windows завершился ошибкой nginx: Git преобразовал скрипт `web-app/nginx/15-check-config.sh` в CRLF. Для повторной проверки обе копии извлечены из Git с `git -c core.autocrlf=false archive`. Текущая версия сохраняет LF этого скрипта через `.gitattributes`.
