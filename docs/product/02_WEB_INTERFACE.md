# S2. Экраны и интерфейсы web-app

## Маршруты

| Экран | Адрес | Действия и переходы |
|---|---|---|
| Вход и профиль | `/login`, `/` | Вход, профиль с ролью и командой, выход. После входа восстанавливается исходный адрес. |
| Чат | `/chat` | История, отправка вопроса и повтор, подсказки, переходы к источникам и заявкам. Из задачи открывается черновик вопроса, который можно отредактировать перед отправкой. |
| План адаптации | `/onboarding`, `/onboarding/tasks/:taskId` | Этапы, прогресс, следующие шаги, сроки и статусы. Из задачи можно открыть связанную заявку или задать вопрос. |
| Заявки | `/actions`, `/actions/:actionId` | Список и карточка. Отправка на согласование и отмена требуют подтверждения в диалоге. |
| Уведомления | `/notifications`, `/notifications/:notificationId` | Список, прочтение, переходы к задаче и заявке. |
| Источник | `/chat/sources/:docId/:anchor?` | Цитируемый раздел или весь документ, дата обновления и пометка тестовой инструкции. |

Переходы из задачи передают её ID в параметре `task`. По нему чат и карточка дают ссылку возврата. При открытии задачи план заново читается из core-api. Черновик вопроса передаётся через состояние маршрута.

## Состояния

| Состояние | Поведение |
|---|---|
| Загрузка и ожидание | Индикатор с текстом. Кнопка операции блокируется на время запроса. |
| Пустые данные | Чат предлагает задать первый вопрос. План, заявки и уведомления показывают сообщение о пустом списке. |
| Ошибка | Сообщение и повтор чтения при временном сбое. При ошибке фонового обновления плана или уведомлений остаются последние загруженные данные. |
| Нет сети | Оболочка показывает уведомление. Повтор отправки чата использует прежний ключ, если исход неизвестен. |
| Истекла сессия | Защищённый маршрут возвращает на вход и сохраняет адрес для возврата. |
| Документ недоступен | При 403 и 404 показывается сообщение и ссылка обратно в чат. |

## Данные и события модулей

Все экраны получают один типизированный `Api` через `useSession()`. Типы берутся из контракта A в `web-app/src/shared/api/schema.ts`.

| Модуль | Вход | События и выход |
|---|---|---|
| `ChatPage` | Сессия, необязательный ID задачи и черновик вопроса | Читает `ChatMessageList`, отправляет вопрос или подсказку и добавляет сохранённый `ChatExchange`. Источник открывается по `doc_id` и якорю из `chunk_id`. |
| `OnboardingPage` | Сессия и необязательный `taskId` из адреса | Читает `Onboarding`, отправляет изменение статуса, показывает возвращённый `Task` и обновляет план. |
| `ActionCard` и `ActionItem` | `ActionCard` из API, дополнительный `footer` | `ActionCard` отображает поля и статус. `ActionItem` выполняет подтверждение и отмену, передаёт серверную карточку через `onChange(card)`. |
| `DocumentPage` | `docId` и необязательный якорь | Читает `Document` через core-api, показывает нужный фрагмент и даёт вернуться в чат. |
| `NotificationsPage` | Сессия и необязательный `notificationId` | Читает `NotificationList`, обновляет запись ответом на отметку прочтения. |

Core-api определяет права, приоритеты и статусы. План и уведомления обновляются при возврате на вкладку и каждые 30 секунд после завершения чтения, пока вкладка видима.
