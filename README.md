# AI-buddy — ИИ-наставник для стажёров

Проект команды на хакатоне Hack&Change 2026, кейс Авито «AI-buddy: ИИ-наставник для стажёров».

> README будет дополнен инструкцией запуска, тестовыми учётками и порядком проверки по мере разработки.

## Текущий план: ML и ядро

Начинаем с [плана сервисов и задач](docs/team/01_ML_CORE_BACKLOG.md): **36 задач**, четыре сервиса (`agent`, `knowledge-service`, `core-api`, `corp-mock`), общий старт и три последовательные интеграции.

- Работаем по задачам без закреплённого распределения на роли.
- Сначала согласуем контракты и заглушки, затем независимо разрабатываем части и собираем рабочую версию после каждой волны.
- Текущий результат проверяем через API и автоматические тесты. Интерфейс, визуальное оформление, презентацию и видео переносим на следующий этап.
- Начало работы: задачи **G0.1–G0.4**, затем параллельные задачи сервисов из плана.

Документ описывает будущую реализацию; сервисы и команды запуска ещё предстоит создать.

## Технические контракты

Все пять промптов начинаются с одинакового блока «Общий контекст команды»: сценарии, стек, тестовые учётки, структура репозитория и контракты API (A — фронтенд ↔ core-api, B — core-api ↔ агент, C — MCP-инструменты, D — core-api ↔ corp-mock). В задаче G0.1 переносим схемы в единый каталог `contracts/`, добавляем контракт E для поиска и ссылаемся на актуальные схемы из промптов. До этого изменения контрактов явно согласуем между потребителями и поставщиками.

Все данные в проекте синтетические. Тестовые инструкции не являются регламентами Авито.
