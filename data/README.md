## База знаний `kb/`

Один документ — один файл Markdown с шапкой:

```yaml
---
id: kb_absence_rules            # совпадает с именем файла
title: "Как оформить отгул или отпуск"
visibility: ["public"]          # public | team:<team_id> | role:<role>; достаточно одного совпадения
tags: ["отгул", "отпуск"]
updated_at: "2026-11-02"
disclaimer: "Тестовая инструкция, не является регламентом Авито"
---
```

У каждого раздела — якорь в заголовке: `## Отгул {#day-off}`. Идентификатор фрагмента — `<id документа>#<якорь>`, например `kb_absence_rules#day-off`.

| Доступ | Документы |
|---|---|
| Всем | `kb_absence_rules`, `kb_access_howto`, `kb_onboarding_first_weeks`, `kb_absence_handover`, `kb_access_statuses`, `kb_onboarding_blockers` |
| Команде Авито Доставка | `kb_who_is_who_delivery`, `kb_delivery_rituals`, `kb_delivery_dev_setup`, `kb_delivery_access` |
| Команде Авто | `kb_auto_release_process`, `kb_auto_frontend_setup`, `kb_auto_access` |
| Наставникам | `kb_mentor_guide` |

доступов, передачу задач перед отсутствием, блокеры адаптации и доступы двух команд.
