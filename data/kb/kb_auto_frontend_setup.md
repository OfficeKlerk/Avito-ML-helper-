# Локальное окружение frontend-разработчика Авто

## Что понадобится {#requirements}

Доступ к GitLab, установленные Node.js и пакетный менеджер команды.

## Первый запуск {#first-run}

1. Склонируй репозиторий интерфейса.
2. Установи зависимости: `npm ci`.
3. Запусти проект: `npm run dev` и открой `http://localhost:3000`.

## Проверки перед ревью {#checks}

Запусти `npm run lint` и `npm test`. Изменение без пройденных проверок на ревью не берут.
