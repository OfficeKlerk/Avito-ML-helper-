# Доступы команды Авто

## Обязательные системы Авто {#required}

Для команды Авто обязательны Confluence, Jira, GitLab и пространство команды
(`team_space`). VPN не входит в обязательный набор этой команды.
Проверь свои текущие доступы перед созданием заявки. Согласует заявки
руководитель команды Павел Зимин.

## GitLab и первый запуск интерфейса {#gitlab}

Для клонирования репозитория интерфейса нужен выданный доступ к GitLab.
Согласованная заявка ещё не гарантирует выдачу: проверь статус `granted`.
После клонирования установи зависимости командой `npm ci`, затем выполни
`npm run dev`. Не используй токены других разработчиков.

## Вопросы по доступам Авто {#help}

Если заявка отклонена, уточни причину у руководителя Павла Зимина.
Если доступ согласован, но не появился, обратись к наставнику Дине Ахметовой
с номером заявки и названием системы. Не отправляй пароли или токены в переписке.
